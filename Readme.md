# Gibberlink Translator

**Un outil de traduction bidirectionnelle entre le français et le Gibberlink, un langage fictif basé sur des règles de transformation personnalisables.**

---

## 📌 Description

**Gibberlink Translator** est une application web légère qui permet de :
- **Traduire du français vers le Gibberlink** en appliquant des règles de transformation prédéfinies ou personnalisées.
- **Traduire du Gibberlink vers le français** (si un dictionnaire inverse est disponible).
- **Étendre les règles de traduction** via un système modulaire.

Ce projet est conçu pour démontrer :
- La manipulation de chaînes de caractères en JavaScript.
- L'implémentation d'une interface utilisateur simple et réactive.
- La gestion de dictionnaires de traduction dynamiques.
