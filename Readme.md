# Gibberlink Translator

**Un outil de traduction bidirectionnelle entre le français et le Gibberlink, un langage fictif basé sur des règles de transformation personnalisables.**

---

## 📌 Description

**Gibberlink Translator** est une application web légère qui permet de :
- **Traduire du français vers le Gibberlink** en appliquant des règles de transformation personnalisées.
- **Traduire du Gibberlink vers le français** (la page decode permet d'inverser).
- **Étendre les règles de traduction** via un système modulaire.

Ce projet est conçu pour démontrer :
- L'implémentation d'une interface utilisateur simple et réactive.
- La generation d'un fichier .MP3 suite a l'ecriture d'une phrase .


Que fait GibberLink ?
GibberLink permet à un agent IA de reconnaître lorsqu'il est en communication téléphonique avec un autre agent IA. Une fois que l'agent IA se rend compte qu'il est en communication avec un autre agent IA, 

GibberLink invite les agents à passer à un protocole de communication plus efficace appelé GGWave.

GGWave est une bibliothèque sonore open source dans laquelle chaque son est un petit morceau de données. Cela permet aux ordinateurs de communiquer plus rapidement et plus efficacement que la parole humaine.

Cependant, pour l'oreille humaine, GGWave ressemble à une série de « bips » et de « boops ».

# Comment cela fonctionne : 

1 - Ouvrir votre navigateur avec le fichier nommé index.html

2 - Ecrire votre texte puis clic sur "Convertir en gibberlink" cela vous donnera un fichier mp3.

#### (Votre texte est maintenant traduit en gibberlink le language de l'IA et des robots informatique).

3 - Donner le ou transmettrez le a votre ami

4 - Il utilisera le fichier nommé decode.html et il faudra le glisser dans la page pour permettre de le decoder gibberlink vers français.

## Vous pouvez le donner a nimporte qui et le faire retraduire avec la page decode.html qui permet de faire le retour en sens inverse. ###
